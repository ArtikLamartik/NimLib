# Code of Conduct

## Our Pledge

We pledge to make NimLib a welcoming, respectful space for everyone, regardless of background or experience level.

## Standards

**Do:**
- Give constructive, specific feedback
- Be patient with contributors new to Nim or systems programming
- Test your changes before submitting
- Be clear about changes

**Don't:**
- Insult or personally attack others
- Spam issues or PRs with off-topic content
- Introduce malicious or breaking code without disclosure

## Enforcement

Unacceptable behavior can be reported to the maintainer via GitHub or Discord. Maintainers may remove contributions or ban contributors that violate this code.
